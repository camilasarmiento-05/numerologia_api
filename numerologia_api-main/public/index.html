API de Numerología

Una API REST que calcula tu perfil numerológico a partir de tu nombre y fecha de nacimiento, y genera lecturas personalizadas con inteligencia artificial.

Cómo funciona

El flujo completo, de principio a fin
  1. Registro El usuario crea una cuenta con su nombre completo, email, contraseña y fecha de nacimiento. POST /auth/register
  2. Inicio de sesión Recibe un token (JWT) que debe enviar en cada petición siguiente para demostrar quién es. POST /auth/login
  3. Cálculo del perfil Con el token, se calculan tres números a partir de su nombre y fecha de nacimiento: vida, expresión y alma. POST /numerology/calculate
  4. Lectura con IA El perfil se envía como prompt a Google Gemini, que genera una interpretación personalizada (amor, trabajo, etc). POST /readings/generate
  5. Compatibilidad Compara su perfil con el de otro usuario y obtiene un puntaje e interpretación generados por IA. POST /compatibility/check

Pruébala en vivo

Cada panel llama directamente a la API desplegada. Sigue el orden de arriba hacia abajo.

1. Registro

POST /api/v1/auth/register

Crea una cuenta nueva.

2. Iniciar sesión

POST /api/v1/auth/login

Obtiene el token que se usará automáticamente en los siguientes pasos.

Sin token todavía

3. Calcular perfil numerológico

POST /api/v1/numerology/calculate

Usa el nombre y la fecha de nacimiento del registro. No necesita más datos.

4. Generar lectura con IA

POST /api/v1/readings/generate

Elige un enfoque para la lectura.

5. Comparar compatibilidad

POST /api/v1/compatibility/check

Necesita el id de MongoDB de otro usuario que ya tenga su perfil calculado.
